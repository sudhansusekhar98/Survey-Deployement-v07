# Survey Deployment v07

A lightweight, client-side survey application for collecting customer feedback and satisfaction data.

## Features

- **Simple Survey Form**: Easy-to-use interface for collecting customer feedback
- **Real-time Results**: View survey statistics and recent submissions
- **Local Storage**: Data persists in browser local storage
- **Responsive Design**: Works on desktop and mobile devices
- **No Server Required**: Pure HTML/CSS/JavaScript implementation

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional software or dependencies required

### Installation

1. Clone this repository or download the files
2. Open `index.html` in your web browser

That's it! No build process or server setup required.

## Usage

### Submitting a Survey

1. Open `index.html` in your browser
2. Fill out the survey form:
   - Name
   - Email
   - Overall Satisfaction (1-5 rating)
   - Comments (optional)
   - Recommendation (Yes/No/Maybe)
3. Click "Submit Survey"
4. View your submission in the results section

### Viewing Results

The application displays:
- Total number of submissions
- Average satisfaction score
- Percentage of users who would recommend
- List of recent submissions (latest 5)

## Files

- `index.html` - Main application page
- `styles.css` - Styling and layout
- `script.js` - Application logic and data management
- `README.md` - This file

## Data Storage

Survey responses are stored in the browser's local storage. Data persists between sessions but is local to the browser. To clear data, clear your browser's local storage.

## Deployment

This is a static web application that can be deployed to:
- GitHub Pages
- Netlify
- Vercel
- Any static web hosting service

Simply upload the files to your hosting provider.
